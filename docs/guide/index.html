EDNiX · DOCUMENTATION

Multi-species MRI and PET processing, explained stage by stage

EDNiX takes BIDS datasets of rodents, bats, dogs, non-human primates and humans through anatomical, functional, PET and CT processing and brings every subject into a common cross-species atlas framework. These guides explain what each stage does to your data and which code does it.

Source-of-truth rule: the guides were checked against the repository code (master, 13 November 2026). When the code changes, update the stage’s input/output table first, then its method text.

Four guides, one per modality

Each guide follows the processing in execution order. Every stage has the same card: why it exists, what it reads, what it creates, how, what to inspect, what comes next, and a developer view with the module and entry point.

ANAT · anatomical MRI

Orientation, bias correction, skull-stripping with manual QC gates, study/longitudinal templates, registration to the atlas, atlases back to native space, FreeSurfer and Workbench surfaces, QC.

modalities/anat · preprocess_anat

fMRI · functional MRI

Slice timing, motion and brain-size-scaled censoring, field-map distortion correction, one-shot resampling, denoising (AFNI / Grandjean / fMRIPrep-style), template space, connectivity and QC.

modalities/fMRI · preprocess_fmri

PET · static and dynamic

Seven registration scenarios (PET-MR, PET/CT, templates), motion correction, SUV and ratios, regional TACs, SRTM/Logan, partial-volume correction, export to template spaces.

modalities/pet · preprocess_pet

CT · for the PET

Reorientation, CT study template, multi-start CT → anatomy / template registration, and the record that the PET pipeline follows.

modalities/ct · preprocess_ct

In which order do the pipelines run?

OrderPipelineNeedsFeeds
1ANATBIDS T1w/T2w, atlas librarytransforms, masks, atlases, surfaces for fMRI / CT / PET
2fMRIANAT of the same subjectdenoised BOLD, matrices, seed maps
2CTANAT (or a CT template, or several CTs)CT registration record
3PETANAT and/or CT record, or a PET templateSUV, ratios, kinetic images in PET, AC-PC and template spaces
Exemples/Study_EDNiX/run_all_ednix.py runs every example launcher in this order (per BIDS folder: anat → CT → PET, anat → func), splits launchers by subject over the available cores, skips jobs whose prerequisite failed, then builds the QC reports. Start with --plan.
For a new species or dataset: run with EDNIX_STRICT=1 (stop at the first failing command), keep the ITK-SNAP/freeview checks on for the first subjects, and look at every skull-strip and registration image before running group statistics.
