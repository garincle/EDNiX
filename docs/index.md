# EDNiX documentation

EDNiX is a multi-species MRI and PET processing pipeline (anatomy, functional MRI, PET, CT) developed at the Institut des Sciences Cognitives Marc Jeannerod (CNRS, Lyon). Source code: [github.com/garincle/EDNiX](https://github.com/garincle/EDNiX).
